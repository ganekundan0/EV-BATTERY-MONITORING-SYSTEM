# EV Battery Monitoring System 🔋

## About the Project
This project is a beginner-friendly Electric Vehicle (EV) Battery Monitoring System developed using Python.

It helps monitor basic battery parameters and calculate electrical power.

## Features
- Battery Voltage Monitoring
- Battery Current Monitoring
- Battery Temperature Monitoring
- Battery Percentage Monitoring
- Electrical Power Calculation
- Basic Battery Status Display

## Technologies Used
- Python
- Visual Studio Code
- GitHub

## Formula Used

Electrical Power:

Power (W) = Voltage (V) × Current (A)

## Project Status
Version 1.0 - Basic Python Simulation

## Future Improvements
- Real-time battery monitoring
- ESP32 integration
- Temperature sensor integration
- Battery monitoring dashboard
- State of Charge (SOC) estimation

## Developer
Kundan

## Disclaimer
This is an educational simulation project.
It is not intended for real EV battery safety monitoring.
