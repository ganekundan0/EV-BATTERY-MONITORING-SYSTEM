
# EV Battery Monitoring System 🔋

## About the Project
This project is a beginner-friendly Electric Vehicle (EV) Battery Monitoring System developed using Python.

It helps monitor basic battery parameters and calculate electrical power.

## Features
- Battery Voltage Monitoring
- Battery Current Monitoring
- Battery Temperature Monitoring
- Battery Percentage Monitoring
- Electrical Power Calculation
- Basic Battery Status Display

## Technologies Used
- Python
- Visual Studio Code
- GitHub

## Formula Used

Electrical Power:

Power (W) = Voltage (V) × Current (A)
